# Referência Orbi

A investigação REA anterior observou a tela pública de entrada, o redirecionamento de `/home/` para login e a apresentação pública dos módulos comerciais, análise de conteúdo, geração de roteiros e pesquisa de creators. Tailwind CDN e Lucide foram observados no HTML de entrada.

Fluxos autenticados, APIs internas, infraestrutura e qualidade dos resultados não foram confirmados. As alegações comerciais da página pública permanecem declarações do fornecedor. O presente piloto utiliza implementação e identidade próprias.
